# KidneyOmics Service website

Static, bilingual project website for the KidneyOmics clinical genomics service pilot.

## Local preview

Open `index.html` directly, or run a local static server from this directory.

## Main files

- `index.html` - site content, styling, and interactions
- `assets/` - project and partner logos
- `downloads/KidneyOmics_Physician_Guide.pdf` - downloadable physician referral guide

## Publishing

The folder can be committed directly to a GitHub repository and published with GitHub Pages.
